# RecursionTheorem

## Overview

RecursionTheorem is a formalization of the Recursion Theorem in the context of Zermelo-Fraenkel set theory. The project includes proofs and lemmas about sets, functions, and natural numbers, which are essential for understanding the Recursion Theorem.

## Mathematical Foundations

The development is based on Zermelo-Fraenkel set theory, which provides the foundational axioms for set theory. The project includes lemmas and theorems that are useful for working with sets, functions, and natural numbers.

## Main Components

1. **Basic Set Theory**: Lemmas about sets, functions, and natural numbers.
2. **Recursion Theorem**: The main theorem of the project, which is formalized in the `recursion.thy` file.

## Usage

To use the RecursionTheorem project, you can explore the `recursion.thy` file, which contains the formalization of the Recursion Theorem. The project is built using the Isabelle/HOL proof assistant, so you will need to have Isabelle installed to work with the project.
